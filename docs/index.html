claude-toolkit ブックマークレット

下のリンクをブラウザのブックマークバーへドラッグ&ドロップするとインストールできる（クリックではなく、リンクをつかんでブックマークバーまでドラッグする）。

Message-ID取得 Title and URL Copy Box path

各ツールの説明

Message-ID取得

Gmailで開いているメールのMessage-IDを Message-ID: <...> 形式でクリップボードにコピーする。詳細は gmail-message-id-bookmarklet/README.md。

Title and URL

現在のページの「タイトル + 改行 + URL」をクリップボードにコピーする。詳細は title-url-bookmarklet/README.md。

Copy Box path

Box.comのファイル/フォルダページで「Box内フォルダパス + URL」をコピーする（Box以外のページではTitle and URLと同じ動作にフォールバック）。詳細は copy-box-path-bookmarklet/README.md。

手動インストール

ドラッグ&ドロップが使えない環境では、各ツールのREADME.mdに記載のコードをブックマークのURL欄に直接貼り付けてもよい。
