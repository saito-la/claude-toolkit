# guides

必要になった時だけ読む参照文書。インストーラが `~/.claude/` 直下へ配置し、指示文書からは `~/.claude/<NAME>.md` の形で参照される。

`instructions/` の断片と違い、`@import` で常時読み込むものではない。読む契機は各文書の冒頭か、`instructions/` 側の指示（例「Gmail への言及時は `~/.claude/GMAIL-MCP.md` を読む」）に書いてある。

## ローカル補足の規約

個人・組織に固有の内容はここに入れない。`~/.claude/<NAME>-local.md` という名前で自分の環境に置き、**共通側の冒頭でその読み込みを指示する**。読む側から見た入口は常に `~/.claude/<NAME>.md` の1つで、`-local` はあれば読む・無ければスキップ。

この形にしているのは、1つのファイルを `<!-- PRIVATE -->` のようなタグで切り取って配布用を生成する運用をやめたため。配布境界はファイル境界＝リポジトリ境界で決める。
