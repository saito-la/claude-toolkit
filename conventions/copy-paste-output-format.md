# コピペ前提テキストの出力規約

作成日：2026-07-05　改訂日：2026-08-01

## 概要

全プロジェクト共通。メール文案・チャット文面・URL・コマンド等「そのまま貼り付ける前提」のテキストを Claude が出力するときの作法。

## 規約

### URLは単独行に置く

メール・文書中のURLは括弧・カッコで囲まない。末尾の `)` がURLの一部と誤認されるため、前後を改行してURLのみの行にする。

### コピペ前提のテキストは `.txt` + `open` か `pbcopy` で渡す

メール文案・チャット文面・URL・コマンド等「そのまま貼り付ける前提」の文字列はチャット内コードブロックで出力しない。

- (a) 一時ディレクトリに `.txt` を書き出して `open <path>` する
- (b) `printf '%s' '...' | pbcopy` でクリップボードに入れる

機微情報（個人情報等）を含む場合はファイルを残さず pbcopy 優先。複数ある場合は1件ずつ、ユーザーが「次」と言ったら次を pbcopy する。

### pbcopy した内容は本文にも省略せずそのまま書く

`pbcopy` に入れた文字列を案内するとき、本文側を `/rename ...`・`git commit -m "..."` のように `...` で省略しない。**完全な文字列をそのまま書く**（短いものは文中に、長いものは本文中に1件だけ提示する）。

理由＝**クリップボードは揮発性**で、ユーザーが貼り付ける前に他のコピー操作で上書きされ得る。上書きされた時点で、本文が省略形だと**何を貼るべきだったか復元できない**（Claude に聞き直す往復が発生する）。本文に全文があれば、そこから拾い直せる。

機微情報を含む場合はこの規約より前段の「ファイルを残さず pbcopy 優先」を優先し、本文には全文を書かず要旨で示す。
