# セッション終了テンポラリファイル自動移動ポリシー

随時更新（2026-08-01 時点）

## 概要

`SESSION-END.md` Step 1（テンポラリファイル整理）を「ユーザー判断」から「Claude自動判断」に変更する。

## 背景

- 当初は「ユーザー判断（番号選択）」方式を採っていた。
- 毎セッションの選択操作がユーザーにとって「判断が面倒」という負担になっていた。
- セッション中に参照したファイルはプロジェクト下に保管するのが自明なケースがほとんどであり、Claude に判断を委ねて問題ない。

## 決定事項

`SESSION-END.md` Step 1 を以下の自動判断方式にする。

### 移動対象の判定ルール

セッション中に参照（Read / Bash / pandoc 等）した Desktop または Downloads 内のファイルを移動対象とする。
参照されていないファイルは放置する（Claude が無関係なファイルを勝手に動かさない）。

### 移動先

`<作業プロジェクト>/attachments/YYYYMMDD/<ファイル名>`

複数プロジェクトにまたがるセッションの場合、参照箇所が主として属するプロジェクトを移動先とする。

### 空フォルダの削除

移動後、移動元ファイルの親フォルダが空になった場合はそのフォルダを削除する。
ただし `~/Desktop/` および `~/Downloads/` ディレクトリ自体は削除しない。

### ユーザー確認

不要。ログに「移動したファイル一覧」を記録する。

## 旧仕様からの変更点

- 判断主体：ユーザー（番号選択）→ Claude（参照有無で自動判断）
- 確認プロンプト：番号一覧を提示して入力待ち → なし
- 空フォルダ削除：しない → する（Desktop/Downloads 本体は除く）
