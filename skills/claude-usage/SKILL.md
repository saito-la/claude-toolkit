# Claude Code の使用状況

以下 `$SKILL` はこの SKILL.md が置かれているディレクトリの絶対パス。symlink 経由で読み込まれていても実体のディレクトリを解決して使う。依存は node だけで、Windows（Git Bash・PowerShell）でも Mac でも同じコマンドで動く。

## 1. 書き出す

端末ごとに1回ずつ実行する。端末名は集計で端末を見分ける名前で、省略するとホスト名になる。

```bash
node "$SKILL/scripts/claude-usage.mjs" export --machine <端末名> --out <置き場>
```

- `<置き場>/<端末名>-sessions.csv`：1セッション1行。プロジェクト（作業フォルダの名前だけ）・入口・最初と最後の時刻・動いていた分数・依頼の数・トークン・モデル
- `<置き場>/<端末名>-spans.csv`：セッションが動いていた区間。集計はこちらから行う
- どちらも BOM 付き UTF-8。依頼の文・応答の中身・ファイルの中身は書き出さない
- 既にファイルがあれば、今回の走査に無いセッションの行は残す。Claude Code が古い記録を消した後も、前回までに書き出した分は失われない。何度実行してもよい

## 2. 集計する

複数の端末の CSV を同じ置き場に集めてから実行する。

```bash
node "$SKILL/scripts/claude-usage.mjs" summary --in <置き場> [--since YYYY-MM-DD] [--until YYYY-MM-DD] [--daily-out <日ごとのCSV>]
```

端末ごとと全端末について、使った日数、使用時間、セッション延べ時間と平均の並行数、2つ以上が並行した時間、最大の並行数、CLI・VS Code・その他の割合、依頼の数、出力トークンを1行ずつ出す。`--daily-out` を付けると日ごとの表を CSV に書く。日ごとの表は spans から毎回作れるので、置き場に保存しなくてよい。

## 3. 数え方

- 動いていた時間：同じセッションの記録（依頼・応答・ツールの実行など）の間隔が5分以内ならつなぎ、つないだ区間の長さを足す。5分を超えて記録が無ければ、その間は数えない。考え込んで手が止まった時間や、長く走るコマンドの待ちは落ちることがある。変えるときは export に `--idle-min <分>` を付ける
- 使用時間：端末ごとに、区間を重ねて「1つ以上のセッションが動いていた時間」を数える。並行したセッションを二重に数えない。全端末の行は、端末をまたいで重ねた時間である
- 平均の並行数：セッション延べ時間を使用時間で割った値
- 入口：記録の `entrypoint` が `cli` なら CLI、`claude-vscode` なら VS Code、それ以外（`claude -p` などの自動実行や、古い版で欄が無いもの）はその他。同じセッションを VS Code と CLI の両方で開いたときは、区間ごとに多いほうで決める
- 依頼：人が打った入力。ツールの結果・スラッシュコマンドの出力・中断の記録・サブエージェントへの指示は数えない
- トークン：応答ごとの `usage` を1回だけ数える（1つの応答が複数行に分かれて記録されても重ねない）。サブエージェントの分も含む
- 再開したセッションが前の履歴を写して持っていても、記録の `uuid` で重複を除く

## 4. 注意

- Claude Code は既定で30日より古い記録を起動時に消す。それより前は数えられない。長く集計するなら、`~/.claude/settings.json` の `cleanupPeriodDays` を大きくしておく
- 時刻と日付の区切りは、実行した端末の時刻帯で決まる
- sessions.csv のプロジェクト名から作業の主題が分かることがある。公開のリポジトリには置かない
