# format-prompt

思いつくままに書いた粗いプロンプト（資料・背景・依頼内容が混在したもの）を、**7ブロックの型**に整形して出力するスキル。

## 使い方

```
/format-prompt <粗いプロンプトをここに貼り付ける>
```

argsが空の場合は「粗いプロンプトを貼り付けてください」と促す。

## 処理手順

1. argsのテキスト全体を読み、目的・背景・依頼・制約・データを把握する
2. 各要素を7ブロックにマッピングする（情報がないブロックは `[要追記]` と明記）
3. 以下の出力フォーマットで整形済みプロンプトを出力する
4. **整形済みプロンプト本体（`【整形済みプロンプト】`〜次の `---` の直前まで／`【整形メモ】`は含めない）を自動的にクリップボードへコピーする。** スクラッチパッドに一時ファイルとして書き出してから投入し、末尾で「クリップボードにコピーしました」と一言添える。ユーザーの追加指示（「クリップボードに入れて」等）を待たない。**投入コマンドは OS で違うので `~/.claude/conventions/copy-paste-output-format.md`「クリップボードへの入れ方」に従う**——Windows で `clip` に読み替えると日本語が化ける。

## 出力フォーマット

```
---
【整形済みプロンプト】

<data>
（素材・資料・データ。XMLタグで囲んで最上部に置く。なければこのブロックごと省略）
</data>

## 役割／コンテキスト
（「あなたは〜です」の形式で立場・専門性を与え、背景状況を含める）

## タスク
（動詞から始まる1〜3文の明確な指示）

## 手順／思考
（複雑な処理のみ番号付きで。単純なら省略）
1. 
2. 

## 制約・ルール
- （禁止事項は「〜しないで」ではなく「〜して」の肯定形に変換して記述）
- 

## 出力フォーマット
（XMLタグ名・型（箇条書き/表/JSON等）・文字数目安を明示）

<examples>
<example>
入力：
出力：
</example>
</examples>
（素材がある場合のみ3〜5個。用意できない場合は省略し「[例: 3〜5個追加すると精度向上]」と注記）

---
【整形メモ】
- 補完・推定した箇所：
- 要追記の箇所：
- 元プロンプトから削除・省略した重複情報：
```

整形後、「このプロンプトで新プロジェクトを開始しますか？修正が必要な箇所はありますか？」と確認する。
