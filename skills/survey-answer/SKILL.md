# survey-answer

## 1. 前提

### 1.1. このスキルの範囲

調査への回答を、毎回同じ手順で進めるための型。どの組織でも使える部分だけを持つ。組織ごとの「どの設問はどの資料を見るか」は、各プロジェクトの情報源の文書（2.3）が持つ。

### 1.2. 送信の扱い

- 回答の送信は相手に届いて取り消せない。集計は公の会議で公表されることもある。「入力して送信して」と言われていても、送信ボタンの前で回答者区分と全回答の一覧を示し、送ってよいかを別に確かめる
- 照会メールは下書きまでで、送るのは依頼者
- 「回答案を作って」は入力・送信の指示ではない

## 2. 手順

### 2.1. 調査を読む

- 依頼メールと添付（回答要領・設問の確認用資料）を取得し、全文をテキストにして読む。docx は `pandoc -t plain --wrap=none` に通し、表の罫線と連続空白を詰めると読める量になる
- 拾うもの：回答者区分（票の分岐）、期限、回答方法（途中保存の可否、同じ端末・同じブラウザでの再開）、公表の範囲、記入するメールアドレスの使い道（重複防止・研修の登録）、同じ施設から複数の回答者が答えてよいか
- Web 票の1ページ目を開き、確認用資料と構成が同じかを確かめる。開くだけでは回答にならない（多くの票は「次へ」で途中保存が始まる）
- 回答要領に「確定作業中」「要確認」の注記があれば、Web 票の文言を正とする

### 2.2. 過去の回答を探す

- プロジェクトの過去の調査フォルダの `answers.md` で、同じ設問・似た設問を探す。人員・体制・料金の設問は調査をまたいで繰り返し出る
- 同じ調査の前回の依頼メールのスレッドを読み、誰がどの区分で答えたか、控えがあるかを確かめる

### 2.3. 情報源を割り当てる

- プロジェクトの「外部調査への回答の情報源」の文書で、設問の種類ごとに一次資料を引く。無ければ、この回の調べで分かった所在から作る
- 設問の種類と、典型的な情報源
  - 人員・体制：年次の報告書の名簿、組織の名簿
  - 実績の件数：案件の台帳、相談の台帳
  - 費用・料金：料金表、実際に出した見積
  - 候補・シーズ：研究や案件の候補の台帳
  - 経験（審査の負担、照会の往復、多施設の運営）：資料に残らないので担当者に照会する
  - 意見・自由記述：組織の方針の文書、依頼者本人の考え
- 数値は一次資料の該当行から取り、基準日を控える。調査側の定義（専任と兼任、対象範囲、前提条件）を読んでから当て、読み替えたときはその根拠を書く

### 2.4. 回答案を作る

- 調査フォルダの `answers.md` に書く。設問の文と選択肢は写さない（確認用資料が正本）
- 1つの設問を1行にし、設問番号・回答・状態・出所を書く。状態は「案」（資料から決めた）、「照会中」（担当者の返事で置き換える）、「判断」（依頼者が決める）の3つ
- 自由記述は文案まで書く。組織の主張を国や団体に届ける場になるので、依頼者の方針に沿わせる
- 未発表の研究・個人や施設を特定しうる情報を書く設問は、書くかどうかを「判断」に回す

### 2.5. 照会する

- 資料に無く、実務の経験でしか答えられない設問だけを照会する。自分の見立てで答えられるものは照会しない
- 担当者への照会メールの下書きを作る。設問番号を挙げ、確認用資料を添付し、選択肢で答えればよい形にする。期限は調査の締切から逆算する
- 返事が来たら `answers.md` の「照会中」を置き換える

### 2.6. 依頼者に確かめる

- 回答者区分、「判断」の設問、自由記述、案の数値を示す
- 照会の返事を待つか、案のまま出すかも決めてもらう

### 2.7. 入力する

- 確定した `answers.md` を見ながら入力する。途中保存は多くの票でブラウザのクッキーに付くので、入力は同じブラウザで続ける
- ページごとに、入力した後の画面のテキストを読み戻して `answers.md` と突き合わせてから次へ進む
- 最後のページの送信ボタンの前で止め、1.2 の確認を取る

### 2.8. 送信と控え

- 承認を得てから送信し、完了画面を保存する
- `answers.md` の案を送信した回答で置き換え、送信した日時を書く
- 依頼メールを処理済みにし、台帳の行を閉じる
- 情報源の文書に、この回で新しく分かった所在と照会先を足す。次の回はそこから始まる

## 3. Web 票の癖

- SurveyMonkey：「Next」でそれまでの回答が保存され、同じ端末・同じブラウザで開くと続きから再開できる。「1つ選択」の設問がチェックボックスで作られていて複数選べることがある。説明の文に従って1つだけ選ぶ
- 自由記述の字数の上限は、入力してみて確かめる
- 選択肢の数の指定（「3つ選択」）が票の側で強制されないことがある。説明の文に従う
