# 質疑のカードと演題のタイマー

以下 `$SKILL` はこの SKILL.md が置かれているディレクトリの絶対パス。symlink 経由で読み込まれていても実体のディレクトリを解決して使う。見た目と操作は speaker-script（読み原稿＋タイマー）に揃えてある。

## 1. 手元メモの md

節（`##`）が画面上のタブ、小節（`###`）が1枚のカード。演題でない節（段取り・講評など）も同じ形で置ける。

```markdown
# <セッション> 手元メモ

## O2 <演者> 先生

15:26 担当（自分が先）

演題の要点（小節の前の本文は「概要」のカードになる）

### 称える

Thank you for a nice talk.

（良い発表をありがとう。）

### 質問

How did you decide who got the pulse?
```

- 節の1行目が「時:分」で始まれば開始予定の時刻として表示し、続く語を札にする。札のある演題はタブの色が変わる（自分の担当の印に使う）
- 英語は会場で読み上げやすいよう短い単文で書く。全体を全角の括弧（…）で囲んだ段落は訳として小さく薄く出し、「訳を隠す」で消せる
- 「- 」の行は箇条書きになる
- 同じ md を markdown-export の `md2pdf.py` に通せば印刷・スマホ用の PDF になる。手元メモの正本は md の1つだけにする

## 2. HTML にする

```bash
python3 "$SKILL/scripts/discussant_cards.py" notes.md -o cards.html --talk 7 --qa 4 [--title "質疑 | 学会名"]
```

画面のひな形は `$SKILL/scripts/cards-view.html`。

## 3. 画面

- 上にタブ（節の最初の語）、左の列に演題のタイマーとボタン、右にカード。縦置きでは上から順に並ぶ
- 「発表開始」を演者が話し始めたときに押すと、発表の残り（青）から質疑の残り（黄）、超過（赤）に変わる。タイマーは演題ごとに持つ
- 「◀」「▶」でカードを送る。演題の最後のカードの次は次の演題
- カードは欄に収まる最大の文字の大きさに自動で合わせる
- 位置とタイマーは localStorage に残り、再読み込みしても戻る。「戻す」で全部消す
- 外部の読み込みは無く、一度開けば通信なしで動く。開いている間は画面が消えないようにする（Wake Lock）

## 4. 配る

演題への批評を含むので、閲覧者を限った置き場に置くか、端末へ直接送る（AirDrop・iCloud Drive の「ファイル」で開く）。
