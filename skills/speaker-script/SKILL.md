# 読み原稿とタイマー

以下 `$SKILL` はこの SKILL.md が置かれているディレクトリの絶対パス。symlink 経由で読み込まれていても実体のディレクトリを解決して使う。

## 1. 読み原稿の md

1スライドを1節にする。節の番号がスライドの番号で、各節の1行目にそのスライドを話し始める目安の時刻を書く。本文は話す言葉のとおりに書き、空行で段落に分ける。

```markdown
# 読み原稿 <演題>

## 1. 表紙

0:00

ご紹介ありがとうございます。

## 2. 背景

0:15

まず背景です。…
```

- 置き場はデッキの元ファイルの隣（例 `slides/script.md`）。読み原稿の正本はこの md だけにし、デッキの発表者ノートにも同じ md から入れる（写しを持たない）
- 目安の時刻は持ち時間の中に割り振る。質疑の時間は含めない
- 長さの目安は日本語で1分あたり約300字。組み立てのたびに、本文の字数と読み上げの目安の分数が表示される
- 既存のデッキに発表者ノートがあれば、その読み筋とスライドの文言から話し言葉に起こす

## 2. HTML にする

```bash
python3 "$SKILL/scripts/speaker_script.py" slides/script.md -o slides/generated/script.html --minutes 20
```

`--title` を省くとページの題は md の H1 になる。画面のひな形は `$SKILL/scripts/script-view.html`。

デッキを組み立てるスクリプトがあるなら、その中で `speaker_script.parse()` を呼び、同じ節をスライドの発表者ノートに入れ、`render()` で script.html も同時に書き出す。こうすると md を保存して組み立てるだけで、ノートと手元の画面が揃う。

```python
import importlib.util, pathlib
p = pathlib.Path.home() / ".claude/skills/speaker-script/scripts/speaker_script.py"
spec = importlib.util.spec_from_file_location("speaker_script", p)
speaker_script = importlib.util.module_from_spec(spec); spec.loader.exec_module(speaker_script)
sections = speaker_script.parse(md_text)          # [{n, title, start, start_label, text}]
html = speaker_script.render(sections, 20, "読み原稿 | 学会名")
```

## 3. 画面

- 横置きでは、左の列に残り時間（経過の帯つき。残り3分で黄、1分で赤）、経過と目安、「早い／予定どおり／遅れ」の札、スライドの番号と題、ボタンを並べ、右は原稿だけにする
- 原稿は欄に収まる最大の文字の大きさに自動で合わせ、スクロールせずに全文が見える
- 会場の PC のスライドとは連動しない。話し手が「▶」「◀」で原稿を送る。タイマーは「開始」で動き、スライドを送っても止まらない
- 再読み込みしても、タイマーと位置は続きから戻る（ブラウザの localStorage。使えない環境では最初から）。「リセット」で最初に戻す
- 「全画面」はブラウザが対応していれば効く。全画面のときにブラウザが左上に出す「✕」を避けて、左の列を少し下げる
- 開いている間は画面が消えないようにする（Wake Lock。効かない OS の版もあるので、本番は端末の自動ロックを切る）
- 外部の読み込みは無く、一度開けば通信なしで動く

## 4. 配る

閲覧者を限った置き場か公開の置き場に、デッキと同じフォルダの `script.html` として置き、端末でその URL を開く。置き場の選び方と上げ方は各自の運用に従う。原稿を直したら組み立てて上げ直す。

本番の前にすること：

- 端末で一度開いておく（ログインが要る置き場なら事前に済ませる）
- 自動ロックを切る
- 「リセット」を押して1枚目にしておき、本番の直前の再読み込みは避ける
- 話し始めた瞬間に「開始」を押す
